# Student Tour-to-Enrollment Analysis

## Overview

This project uses Python to analyze the student tour-to-enrollment funnel and identify patterns that can support enrollment and outreach decisions.

## Objectives

- Measure tour-to-enrollment conversion
- Analyze enrollment outcomes
- Compare performance across locations and lead sources
- Create visualizations to communicate key findings
- Generate actionable insights from enrollment data

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis

The project focuses on transforming enrollment-related data into meaningful metrics and visual insights. The analysis can help identify stronger-performing locations and lead sources and highlight opportunities to improve conversion.

## Project Scope

This repository contains the Python analytics and visualization component of the project. It does not represent the full application platform or its frontend/backend infrastructure.
